iCloudPD Studio
把 iCloud 照片与视频，按原始画质增量备份到本地
================================================

怎么打开
--------
双击「iCloudPD Studio.exe」。不需要安装 Python，也不需要另外安装 icloudpd，
下载引擎（icloudpd.exe）就在同一个文件夹里。

第一次打开时，程序会在 exe 旁边生成 data 文件夹，用来存配置、任务日志和
缩略图缓存。想换地方存，把这个文件夹整个搬走再指定路径即可。

怎么用
------
1. 在「同步下载」里填 Apple ID。
2. 第一次登录会触发双重认证，验证码会出现在任务面板的输入框里，填进去提交。
   成功后会话会保存在本机，之后通常不用再输密码。
3. 选择同步范围（全部 / 最近 N 个 / 日期区间 / 指定相册）、媒体类型和保存位置。
   建议先勾「仅预览待下载清单」，确认范围没选错。
4. 点开始，然后去干别的。「任务记录」里能看到实时进度，已下载、已跳过、
   错误数量都在跳。
5. 「照片图库」里可以浏览已经落到硬盘上的文件，支持搜索和灯箱预览。

中断了怎么办
------------
直接重新跑同一个配置。icloudpd 会跳过已经下载过的文件，只补新增的部分。
关机、断网、拔硬盘都不会损坏已经下好的照片。

关于隐私
--------
服务只监听本机回环地址（127.0.0.1），局域网里其他设备连不上。
没有账号系统、没有遥测、没有云端中转，照片不经过任何第三方服务器。
密码不写入配置文件和日志，只在任务运行期间留在内存里。

想验证这一点，可以断网后打开程序——除了同步功能，其他都能正常使用。

已知限制
--------
- 开启了 ADP（高级数据保护）的 Apple ID 无法通过 icloudpd 登录，这是上游限制。
- 同时只允许运行一个同步任务，避免两个进程争用同一个账户的会话。
- 程序重启后，之前运行中的任务会标记为「已中断」，不自动恢复。
- 不提供定时任务，需要定期备份可以用 Windows 任务计划程序调用 icloudpd.exe。

如果打开后提示缺少 WebView2
---------------------------
Windows 10/11 一般自带 Microsoft Edge WebView2 Runtime。
如果没有，去微软官网下载安装「WebView2 Runtime」即可。
