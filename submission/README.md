## 6. 一个提醒

「完成度」占 40 分，评审最看「能跑起来」。所以在分享和投稿里，**优先让人下载并打开界面**，而不是先讲技术实现。命令预览那张图（`download.png`）是最有说服力的一张——它一眼就能说清「这不是套壳网页，是真的在驱动命令行引擎」。
